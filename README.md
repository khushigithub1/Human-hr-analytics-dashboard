# 📊 Human HR Analytics Dashboard

## 📌 Project Overview

The Human HR Analytics Dashboard is an end-to-end Data Science and Machine Learning project developed to analyze employee workforce trends, employee satisfaction, attrition patterns, and performance insights within an organization.

This project combines:
- Data Analysis
- Interactive Dashboard Development
- Machine Learning Prediction
- Business Insights & Recommendations

The dashboard was developed using Python, Streamlit, Plotly, Pandas, Seaborn, Matplotlib, and Scikit-learn.

# 🤖 Machine Learning Model

A Machine Learning model was developed to predict employee performance ratings based on important employee attributes.

## 🔹 Features Used for Prediction

- Age
- Distance From Home
- Job Satisfaction
- Percent Salary Hike
- Years At Company
- Years Since Last Promotion
- Environment Satisfaction
- Training Times Last Year

## 🔹 Machine Learning Algorithm

- Random Forest Classifier

## 🔹 Model Accuracy

✅ Approximately 88.75% Accuracy

# 📌 Business Insights

The analysis generated several important business insights:

- Salary hike percentage was identified as one of the strongest factors influencing employee performance.
- Employees with low salary growth demonstrated lower performance and engagement levels.
- Environment satisfaction strongly impacts employee productivity and retention.
- Employees remaining in the same role for extended periods showed declining performance trends.
- Attrition rates were higher among employees with lower satisfaction scores.

---

# ✅ Strategic HR Recommendations

Based on the analysis, the following recommendations are proposed:

- Implement transparent and structured salary review processes.
- Conduct regular employee satisfaction and engagement surveys.
- Improve promotion opportunities and role rotation programs.
- Focus on enhancing workplace culture and managerial support.
- Use predictive analytics during performance appraisals and workforce planning.
- Identify at-risk employees early and provide proactive interventions.
